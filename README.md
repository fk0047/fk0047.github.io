# fk0047.github.io

Portfolio of Fahad Khan: AI Product Manager, Product Owner, Technical Project Manager and Fractional CTO.

Live at https://fk0047.github.io

Built with [Astro](https://astro.build) and deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml` on every push to `main`.

- `src/pages/index.astro`: the page, its styles and its scripts
- `src/data/site.js`: projects, skills, certifications, experience and recommendations
- `src/styles/global.css`: colours, type and motion
- `public/`: photos, logos, screenshots and certificate PDFs

Run locally with `npm install` then `npm run dev`.
